## Run

Each exercise is an independent Java console program. From the Lab 4 directory, run one exercise with:

```bash
cd ex1
javac -d out Main.java
java -cp out Main
```

Replace `ex1` with `ex2`, `ex3`, `ex4`, or `ex5` to run another exercise. A Java JDK is required.
